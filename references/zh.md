# 中文界面 · Chinese UI

A Chinese patch for Stageshow. Read this whenever the brief is in Chinese, the product's users are, or the user writes to you in Chinese: the scene's words are then Chinese, and Chinese type has its own rules. Everything else in the skill (framing, motion, craft, the cursor) holds unchanged.

说明用中文写，因为规则本身就是中文的规则。Each rule has its reason; the ones that matter most are marked.

## 启用 · Switching it on

```tsx
import '../../kit/zh.css'
import { typeZh } from '../../kit/zh'

<div lang="zh-CN">
  <Stage className="look-zh" theme="light" ...>
```

- **`lang="zh-CN"` 必须有。** 没有它，Chrome 会按日文字形渲染一部分汉字（骨、直、与、复 这类字的笔画会不一样），整张图会被中文读者一眼看出"不对劲"。加在舞台外任意一层祖先上即可；`:lang(zh)` 规则会接住。
- **`look-zh`** 叠在任意内置主题（light、dark、glass、blueprint）之上，只改字体、密度和几个西文习惯。产品自己的 look 照常叠加，写在它后面；品牌字体放在 `--ss-font` 最前，后面必须保留 zh.css 的 CJK 回退链。
- 字体栈是"系统的拉丁字体 + 系统的中文字体"：macOS 上是 SF + 苹方，Windows 上是 Segoe UI + 微软雅黑，这就是一个原生应用在那台机器上的样子。不要为了统一而把微软雅黑放在拉丁字体前面，它的拉丁字形很差。

## 字号与行高 · Size and leading

同样的像素字号，汉字比拉丁字母显得更小、更密，笔画更多。每一档都比西文版本大 1 px、行高多一成：

| 用途 | 西文 kit 默认 | 中文 |
|---|---|---|
| 正文、列表行 | 12–13px / 1.4 | 13–14px / 1.5 |
| 标题 | 13px 600 | 14px 600 |
| 次要说明、导航 | 10.5–11px | 11.5–12px，**不低于 11px** |
| 数字、金额 | 13px tabular | 不变，数字仍是拉丁字形 |

`look-zh` 已把 `--ss-row` 和 `--ss-control` 各加大 2px，`.ss-text` 行高设为 1.5。示例里自己写的 `font-size` 要按上表手动调。

## 字重 · Weight

多数系统中文字体只有 Regular 和 Bold 两档：苹方有六档，微软雅黑只有两档，思源黑体有七档但要装。按两档设计：400 是正文，600 是强调；500 在 Windows 上会落回 400，700 和 600 看起来一样。层级靠颜色（`--ss-text-strong` / `--ss-text` / `--ss-text-faint`）和字号，不靠字重的细微差别。

## 不做的事 · Never

- **不要字间距。** `letter-spacing` 对汉字只会撑出像空格一样的缝。zh.css 已在舞台根和几个 kit 部件上归零。
- **不要大写。** `text-transform: uppercase` 对汉字无效，对混排里的英文反而突兀。
- **不要斜体。** 中文字体没有斜体，浏览器会把字形硬拉斜。引用、说明、占位文字用常规体 + 浅一档的颜色。
- **不要把英文界面逐字翻译。** "Customers" 是"客户"，不是"客户们"；"Overview" 是"概览"；"Reports" 是"报表"；"Settings" 是"设置"。按钮两个字（保存、发送、确认、取消、添加），最多四个字（添加成员、导出报表）。翻译腔比空白更假。

## 标点与混排 · Punctuation and mixed script

- 中文句子用全角标点：，。：；！？「」（）。数字、代码、网址、单位之间用半角。
- 中英文、中文和数字之间留一个空格：`共 12 个文件`、`Figma 的评论`、`已同步到 iCloud`。数字和百分号、度数之间不留：`12%`、`36.5°`。全角标点前后都不留空格。
- 行尾标点不能悬在行首：zh.css 设了 `line-break: strict`。

## 数字、货币、日期 · Figures

| 项 | 写法 | 不要 |
|---|---|---|
| 金额 | `¥1,240`、`¥72.00`、`$860`（外币保留原符号） | 一千二百四十元、`1240 元` 在表格里 |
| 大数 | `12,480`、`3.2 万`（口语场景） | `12480` |
| 日期 | `11月6日`、`2026年11月6日`、表格里 `11-06` 或 `2026-11-06` | `Nov 6`、`6/11` |
| 时间 | `14:30`、`下午 2:30`（消息、锁屏） | `2:30 PM` |
| 相对时间 | `刚刚`、`3 分钟前`、`昨天`、`周二` | `3m ago` |
| 数量 | `3 位成员`、`12 条未读`、`2 个文件` | `3 members` 直译成 `3 成员` |
| 手机、锁屏 | 中文 iOS：`星期四 11月6日`，通知 `现在`、`5分钟前` | 英文 iOS 的 `now` |

数字永远用阿拉伯数字和拉丁字形，走 `tabular-nums`；这是中文产品的实际做法，也让金额列能对齐。

## 名字 · Names

真实但不出名的名字，和英文示例里 "Halvorsen & Co"、"Jackson Hot Yoga" 同一个量级：

- 人名：林雨桐、王晓敏、陈子墨、周一帆、黄泽宇、吴思齐。**不要张三、李四、王五**，那是中文的 lorem ipsum，读者一看就知道是占位。
- 公司和店名：远山科技、青禾设计工作室、北辰咖啡、云栖数据、拾光书店、明澈律所、西岭健身。两到四个字加一个行业词，像真的营业执照。
- 头像首字母：`Avatar` 取名字第一个字，中文就是姓，正好。英文产品里的双字母 monogram 在中文里是单个汉字，`size` 可以比英文小一号。
- 地址：`上海市徐汇区漕溪北路 88 号`、`杭州市西湖区`。网址仍是英文：`dashboard.yuanshan.co`。

## 占位灰条 · Placeholder bars

灰条替代的是"一行文字"，长度要像那一行中文的长度。一个汉字约等于一个字号宽：14px 的字，六个字的标题约 84px；英文平均一个字母约半个字号。同样的词，中文灰条比英文短三到四成。

| 内容 | 字数 | 14px 下的宽度 |
|---|---|---|
| 导航项、按钮 | 2–4 | 28–56px |
| 列表标题、人名 | 3–6 | 42–84px |
| 一句说明 | 10–16 | 140–224px |
| 金额列 | `¥` + 4–6 位 | 48–64px |

真字只放在故事所在的那几处，其余用灰条，这条规则和英文版一样。

## 打字动画 · Typing

中文是经过输入法打出来的：字母先进入候选条，然后一整个词上屏。`a.type` 一次出一个字，看上去像在粘贴。用 `typeZh`，它按词提交，每个词之前停一下（选候选的那一瞬）：

```ts
await typeZh(a, 'draft', '帮我整理这周的发票')          // 自动分词
await typeZh(a, 'draft', '帮我|整理|这周的|发票')       // 手动指定切分
await typeZh(a, 'draft', '把 Figma 的 3 个评论发给我')  // 英文和数字各算一个词
```

默认每词 150ms 左右，长词更慢。想画出候选条本身（输入法的那一小条）是另一个物件，一般不值得：观众认的是"一个词一个词地出现"这个节奏。

## 窗口、手机、系统件 · Chrome

- 浏览器窗口的标签标题、地址栏是中文产品本来的样子：`客户 · 远山科技`，网址保持英文。
- 终端里中文走 `--ss-mono` 的 CJK 回退；没装等宽中文字体的机器上会落到系统黑体，宽度不等，所以终端输出里的中文只放在提示语，列对齐的部分仍用英文和数字。
- 手机锁屏的日期和通知时间用上表的中文写法；`LockScreen` 和 `Notification` 的文字是 props，传中文即可。
- 键盘：`Keyboard` 是英文 QWERTY，正好对应拼音输入，不需要改；要是故事里出现候选条，它是一个 `Bar` 行加几个 `Text`，放在键盘上方 6px。

## 检查 · Check

拍完对着看，中文读者一眼会抓到的几样：

1. **字形**：骨、直、与、复、角、沿。笔画像日文的，说明缺 `lang="zh-CN"`。
2. **假粗假斜**：被硬加粗或硬拉斜的字，边缘发毛。
3. **翻译腔**：按钮超过四个字，标签带"们""的"，或者直接露出英文标签。
4. **标点**：中文句子里的半角逗号句号，行首的逗号，中英文之间没有空格。
5. **灰条过长**：按英文字母数画的灰条，比旁边真字长一倍。
6. **张三李四**：任何一个。
